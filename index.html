⚙️ เชื่อมต่อ Firebase Project ของคุณ (ฟรีตลอดชีพ)

วางโค้ด firebaseConfig ที่ได้จาก Google Firebase Console เพื่อเปิดระบบคลาวด์ของคุณเอง ปลอดภัย 100%

📖 วิธีสร้าง Firebase ฟรีใน 3 นาที (คลิกดูขั้นตอน)
  1. เปิดเว็บไซต์ console.firebase.google.com แล้วล็อกอินด้วย Gmail
  2. กด "Add project" (สร้างโปรเจกต์) ตั้งชื่อ เช่น my-work-tracker แล้วกด Continue จนเสร็จ
  3. ที่เมนูซ้ายมือ เลือก Build > Realtime Database กด "Create Database" แล้วเลือก Start in Test mode
  4. ที่เมนูซ้ายมือ เลือก Build > Authentication กด "Get started" เลือกเปิดใช้งาน Email/Password และ Anonymous
  5. ไปที่ Project Settings (รูปเฟืองมุมซ้ายบน) เลื่อนลงมาที่ "Your apps" กดไอคอนเว็บ </>
  6. คัดลอกโค้ดในส่วน const firebaseConfig = { ... } นำเฉพาะก้อนปีกกา { ... } มาวางในช่องด้านบนนี้ แล้วกด "บันทึกการตั้งค่า Firebase" ได้ทันที!
