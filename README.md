# 📅 Work Tracker - ระบบปฏิทินบันทึกงานรายวัน (Template Edition)

ปฏิทินติดตามงานรายวัน (Daily Work & Task Tracker) สไตล์โมเดิร์น พร้อมระบบจัดกลุ่มแท็กสีสไตล์ Trello ออกแบบมาให้ใช้งานง่าย รวดเร็ว รองรับการแนบไฟล์เอกสาร/ภาพ พร้อมอัปโหลดขึ้น Google Drive ส่วนตัว และทำงานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## ✨ ฟีเจอร์เด่น (Features)

- 🗓️ **ปฏิทินรายเดือนอัจฉริยะ**: แสดงรายการงานแต่ละวัน พร้อม Badge สรุปจำนวนงานและสถานะเสร็จสิ้น
- 🏷️ **แท็กสีสไตล์ Trello**: จัดการหมวดหมู่งานด้วยแท็กสีสดใส สามารถเปลี่ยนชื่อแท็กและเลือกพาเลตสีได้ตามต้องการ
- 📎 **ระบบแนบไฟล์เอกสาร & รูปภาพ (PDF / Images)**:
  - รองรับการแนบรูปภาพ (PNG, JPG, WebP) และไฟล์เอกสาร PDF
  - **Hover Preview**: ชี้เมาส์ที่ป้ายไฟล์เพื่อดูภาพพรีวิวหรือรายละเอียด พร้อมปุ่มลัดสำหรับเปิดดูไฟล์เต็มหรืออัปโหลด
  - **Google Drive ส่วนตัว**: กดอัปโหลดไฟล์ขึ้น Google Drive ส่วนบุคคลของผู้ใช้แต่ละคนได้โดยตรง
  - **Smart Deduplication**: ตรวจจับและป้องกันการอัปโหลดไฟล์ซ้ำ ทั้งในเครื่องและบน Google Drive
- 🏖️ **โหมดกำหนดวันหยุด (Holiday)**: คลิกเปิด-ปิดวันหยุดประจำวัน พร้อมแสดงแท็กไอคอน 🏖️ วันหยุด และเปลี่ยนโทนสีช่องปฏิทิน
- ↩️ **ระบบ Undo (ย้อนกลับ)**: กดคีย์ลัด `Ctrl + Z` หรือกดปุ่ม **ย้อนกลับ (Undo)** บนการ์ดแจ้งเตือนมุมซ้ายล่าง เพื่อกู้คืนสถานะก่อนหน้าได้ทันที (รองรับทั้งการลบงาน, สลับวันหยุด, ลากย้ายวัน)
- 🔀 **Drag & Drop สะดวกสบาย**: 
  - ลากย้ายงานเดี่ยวข้ามวันได้ทันที
  - ลากหัววันเพื่อ **"ย้ายงานทั้งวัน"** ไปยังวันอื่นได้ในคลิกเดียว
- 📝 **Day Modal 2 คอลัมน์**: หน้าต่างจัดการงานรายวันแบ่งชัดเจนระหว่าง *งานที่ต้องทำ* และ *งานที่เสร็จแล้ว*
- 👁️ **Colorblind Accessible**: โหมดลวดลายกราฟิกบนแถบสี ช่วยให้ผู้มีความบกพร่องทางการมองเห็นสีจำแนกแท็กได้อย่างชัดเจน
- 💾 **Offline-first 100%**: บันทึกข้อมูลลงในเครื่องทันทีผ่าน LocalStorage ไม่ต้องต่อเน็ตก็ใช้งานได้เต็มรูปแบบ
- 📦 **Export / Import**: สำรองข้อมูลเป็นไฟล์ JSON หรือนำข้อมูลกลับมาเปิดใช้งานได้ทุกเมื่อ
- ☁️ **Cloud Sync & Google Login (Optional)**: เชื่อมต่อ Firebase Realtime Database เพื่อซิงก์ข้อมูลแบบเรียลไทม์ระหว่างคอมพิวเตอร์และมือถือ

## 🚀 วิธีเริ่มต้นใช้งาน (Quick Start)

### วิธีที่ 1: ใช้งานแบบออฟไลน์ทันทีบนเครื่องของคุณ
1. ดาวน์โหลดโฟลเดอร์นี้ลงในเครื่องของคุณ
2. ดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานผ่านเว็บเบราว์เซอร์ (Google Chrome, Edge, Safari ฯลฯ) ได้ทันที
3. เริ่มต้นบันทึกงานและจัดการตารางงานของคุณได้เลย!

---

### วิธีที่ 2: นำขึ้นออนไลน์ฟรีผ่าน GitHub Pages (พร้อมใช้งานบนมือถือ)
1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้อัปโหลดขึ้น GitHub Repository ของคุณ
2. ไปที่ **Settings** ของ Repository > เมนู **Pages** ด้านซ้าย
3. ในส่วน **Build and deployment > Branch** ให้เลือก `main` (หรือ `master`) แล้วกด **Save**
4. รอระบบประมวลผลประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น:
   ```
   https://<username>.github.io/<repository-name>/
   ```
5. เปิดลิงก์จากมือถือหรือคอมพิวเตอร์ได้ทันที!

---

## 📁 การตั้งค่า Google Drive API และโฟลเดอร์จัดเก็บไฟล์

ระบบถูกออกแบบให้ผู้ใช้แต่ละคนสามารถอัปโหลดไฟล์แนบเข้าสู่ **Google Drive ส่วนตัวของตนเอง** ได้อย่างปลอดภัย

### 1. วิธีเปิดใช้งาน Google Drive API ในโปรเจกต์ Google Cloud
หากผู้ใช้กดอัปโหลดไฟล์แล้วได้รับแจ้งเตือนว่า:
> `⚠️ Google Drive API has not been used in project... or it is disabled. Enable it by visiting console.developers.google.com...`

ให้ผู้ดูแลโปรเจกต์เปิดสิทธิ์ API ตามขั้นตอนดังนี้ (ทำเพียงครั้งเดียว):
1. ไปที่หน้าจัดการ API: 👉 **[Google Cloud Console - Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com)**
2. เลือกโปรเจกต์ที่ตรงกับ Firebase Project ของคุณ (เช่น `my-work-tracker-...`) จากแถบด้านบน
3. กดปุ่มสีน้ำเงิน **"ENABLE" (เปิดใช้งาน)**
4. รอ 1–3 นาทีเพื่อให้ระบบ Cloud ของ Google เปิดใช้งานสิทธิ์ จากนั้นสามารถใช้งานได้ทันที

> **สิทธิ์การเข้าถึง (Scope):** ระบบขอเฉพาะสิทธิ์ `drive.file` ซึ่งเข้าถึงได้เฉพาะไฟล์ที่อัปโหลดผ่านเว็บแอปนี้เท่านั้น ปลอดภัยต่อไฟล์ส่วนตัวอื่นๆ ใน Drive ของผู้ใช้ 100%

---

### 2. วิธีเลือกโฟลเดอร์ Google Drive สำหรับจัดเก็บไฟล์
หากไม่ระบุโฟลเดอร์ ไฟล์จะถูกบันทึกไว้ที่หน้าแรกของ Google Drive ("ไดรฟ์ของฉัน") แต่หากต้องการให้ไฟล์ไปรวมอยู่ในโฟลเดอร์ที่จัดเตรียมไว้:

1. เปิด **Google Drive** แล้วเข้าไปยังโฟลเดอร์ที่ต้องการจัดเก็บไฟล์ (หรือสร้างโฟลเดอร์ใหม่ เช่น `จัดเก็บเอกสาร`)
2. ดูที่ช่อง URL ด้านบนของเบราว์เซอร์ จะมีรูปแบบดังนี้:
   ```
   https://drive.google.com/drive/folders/1xF51wwGdvrCjMzzYC3CR84xMr5VZQC9K
   ```
3. คัดลอกรหัสด้านหลังคำว่า `/folders/` (ในตัวอย่างนี้คือ `1xF51wwGdvrCjMzzYC3CR84xMr5VZQC9K`)
4. นำรหัสไปใส่ในไฟล์ `firebase-config.js`:
   ```javascript
   // โฟลเดอร์ Google Drive สำหรับจัดเก็บไฟล์เอกสารและรูปภาพ (ใส่ Folder ID หรือปล่อยว่างไว้)
   window.GOOGLE_DRIVE_FOLDER_ID = "1xF51wwGdvrCjMzzYC3CR84xMr5VZQC9K";
   ```
5. บันทึกและอัปเดตไฟล์ขึ้น GitHub Pages เป็นอันเสร็จสิ้น ทุกไฟล์ที่อัปโหลดจะถูกส่งไปยังโฟลเดอร์นี้โดยตรง

## ☁️ วิธีเชื่อมต่อระบบ Cloud Sync ข้ามเครื่อง (Firebase)

หากคุณต้องการให้ข้อมูลในมือถือและคอมพิวเตอร์ซิงก์ตรงกันแบบอัตโนมัติ สามารถเชื่อมต่อ Google Firebase (ฟรี) ได้ตามขั้นตอนดังนี้:

### ขั้นตอนที่ 1: สร้างโปรเจกต์ใน Firebase
1. ไปที่ [Firebase Console](https://console.firebase.google.com/) แล้วล็อกอินด้วยบัญชี Google
2. กด **"Add project"** (สร้างโปรเจกต์ใหม่) ตั้งชื่อโปรเจกต์ตามใจชอบ
3. ไปที่เมนู **Project Settings** (ไอคอนฟันเฟืองมุมซ้ายบน) > เลื่อนลงมาที่หัวข้อ **Your apps** แล้วกดเลือกไอคอน **Web (`</>`)**
4. ตั้งชื่อเว็บแอป แล้วคัดลอกส่วนที่เป็นโค้ด `firebaseConfig`

### ขั้นตอนที่ 2: เปิดใช้งาน Realtime Database
1. ในแถบเมนูด้านซ้าย เลือก **Build > Realtime Database** แล้วกด **Create Database**
2. เลือกตำแหน่งที่ตั้งฐานข้อมูล (แนะนำเลือก `asia-southeast1` สิงคโปร์ เพื่อความเร็วสูงสุดในไทย)
3. ในขั้นตอน Security rules ให้เลือก **Start in test mode** ก่อนได้

### ขั้นตอนที่ 3: เปิดใช้งานการเข้าสู่ระบบ (Authentication)
1. ในแถบเมนูด้านซ้าย เลือก **Build > Authentication** > กด **Get Started**
2. ในแท็บ **Sign-in method** ให้เลือกเปิดใช้งาน **Google** แล้วใส่ Support email
3. ไปที่แท็บ **Settings > Authorized domains** แล้วกด **Add domain** ใส่โดเมนของ GitHub Pages ของคุณ (เช่น `<username>.github.io`)

### ขั้นตอนที่ 4: ใส่ค่า Config ในโปรเจกต์
เปิดไฟล์ `firebase-config.js` แล้วนำค่าที่ได้จากขั้นตอนที่ 1 มาวาง เช่น:

```javascript
window.FIREBASE_CONFIG = {
  apiKey: "YOUR_API_KEY",
  authDomain: "your-project-id.firebaseapp.com",
  databaseURL: "https://your-project-id-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "your-project-id",
  storageBucket: "your-project-id.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef..."
};
```

*(หรือสามารถกดปุ่ม **"ซิงก์ Cloud"** ที่มุมขวาบนของเว็บ แล้ววาง JSON Config ผ่านหน้าเว็บโดยตรงก็ได้เช่นกัน)*

## 📁 โครงสร้างไฟล์ในโฟลเดอร์ Template

```
Template/
├── index.html           # โครงสร้างหน้าเว็บและ Modal ต่างๆ
├── style.css            # ธีมสี Dark theme, สไตล์ปฏิทิน และ Responsive Design
├── app.js               # ตรรกะการทำงานทั้งหมด (จัดการงาน, ปฏิทิน, แนบไฟล์, Drive, Undo, Sync)
├── firebase-config.js   # ไฟล์สำหรับกรอก Firebase Config และ Google Drive Folder ID
└── README.md            # คู่มือการติดตั้งและใช้งานฉบับนี้
```

## 🔒 ความปลอดภัยและความเป็นส่วนตัว
- เวอร์ชัน **Template** นี้ไม่มีการฝัง API Key หรือรหัสผ่านส่วนตัวใดๆ ในซอร์สโค้ด
- เริ่มต้นด้วยตารางงานว่างเปล่า ไม่ติดค้างตารางงานส่วนบุคคล
- หากใช้งานแบบ Localhost ข้อมูลทั้งหมดจะถูกเก็บอยู่ในเครื่องของคุณเอง 100%
- การเชื่อมต่อ Google Drive ใช้สิทธิ์แบบเฉพาะเจาะจง (`drive.file`) เพื่อความปลอดภัยสูงสุด
